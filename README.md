# E-commerce Platform

A modern e-commerce application built as a learning and portfolio project.

The project currently focuses on frontend development with Angular and will gradually evolve into a full-stack application.

## Current Status

The frontend is currently under development.

At this stage, the main focus is learning and applying modern Angular concepts, frontend architecture, API integration, testing, and professional development practices.

## Tech Stack

### Frontend

- Angular 21
- TypeScript
- RxJS
- Signals
- SCSS
- Vitest

### Backend — Planned

- Java
- Spring Boot

### Database — Planned

- PostgreSQL

## Project Structure

```
ecommerce-platform/
└── frontend/
```
The backend and additional infrastructure will be added as the project evolves.

## Getting Started
- Prerequisites
- Node.js
- npm
- NVM recommended

### Frontend

```
cd frontend
nvm use
npm ci
npm start
```
The application will be available at:
```
http://localhost:4200
```
## Project Goals
- Build a robust Angular application using modern Angular practices
- Integrate with public APIs
- Practice automated testing
- Apply Git and GitHub workflows
- Learn scalable frontend architecture
- Gradually evolve the project into a full-stack application
- Build a production-oriented portfolio project

## Roadmap

The project will initially use public APIs while the Angular frontend is developed.

Later stages will introduce:

- Spring Boot REST API
- PostgreSQL
- Authentication and authorization
- Docker
- CI/CD
- Cloud deployment
